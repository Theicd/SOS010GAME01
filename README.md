# SOS010GAME01

NZ:P for SOS. This repo stays separate from SOS-main.

## Web (browser / phone)

Folder `web/` is the WebGL client (same kind as [nzp.gay](https://nzp.gay)).

Open `web/index.html` through an HTTP server (not as a local file).

Source: [nzp-team/nzp-team.github.io](https://github.com/nzp-team/nzp-team.github.io)
